# Game Art Skins

Read [DESIGN.base.md](DESIGN.base.md) before applying any skin. The base file defines interaction, accessibility, and S1 portrait constraints; skins only alter genre expression.

| Skin | Use |
| --- | --- |
| [Mystery Puzzle](skins/mystery-puzzle.md) | Clues, curses, investigations, survival puzzles |
| [Romance Idol Anime](skins/romance-idol-anime.md) | Idol performance and emotional routes |
| [Ancient Timetravel](skins/ancient-timetravel.md) | Historical survival, court, and commerce stories |
| [Sci-Fi Apocalypse](skins/sci-fi-apocalypse.md) | Ruined future, space, machine, and survival stories |
| [Chinese Wuxia Xianxia](skins/chinese-wuxia-xianxia.md) | Martial arts, cultivation, mythic quests |

Current mapping: `snow-border`, `market-gate`, and `palace-market` use `ancient-timetravel`; `life-hexagram` uses `mystery-puzzle`.
